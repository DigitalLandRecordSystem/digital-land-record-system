Key management

Two keypairs per account. RSA protects account and profile data; ECC protects deed content. Private keys are stored encrypted under the server master key and never appear here.

Public keys are published, not secret — see the key directory. They are covered by an HMAC tag so that substituting one is detected.

Rotating issues a new version and retires the current one. Retired keys are kept, not deleted, so records written under them stay readable — each record records the key version that encrypted it.

Migration re-encrypts your existing records under the current keys. Without it, older records stay readable through their retired key indefinitely.
